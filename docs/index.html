Get yours in one line.

No dependencies and about 8.9 KB gzipped. Each pipkin is an SVG string, so it works in React, Vue, Svelte or a plain template.

Install
$ i pipkins
Use it
Avatar.jsx 
import { pipkin } from "pipkins";

export function Avatar({ id }) {
  const svg = pipkin(id, { size: 32 });
  return <span dangerouslySetInnerHTML={{ __html: svg }} />;
}

No bundler? Import it from a CDN: https://cdn.jsdelivr.net/npm/pipkins@0/dist/pipkins.min.js

Eight moods

A small API, no surprises.

Everything returns a string or a plain object. Bad values throw a TypeError that names the accepted ones.

Functions

FunctionReturnsNotes
pipkin(seed, options?)SVG stringOne pipkin. A seed is any name, id or email, a lineage, or a genome.
fuse(seeds, options?)SVG stringOne pipkin for up to 9 members. Order and duplicates are ignored.
breed(a, b, { child? })genomeOrder-free. child picks a sibling (0, 1, 2…).
pipkinUri, fuseUridata URIThe same, ready for src attributes.
describe(seed)stringAlt text, such as "pink bunny with dot eyes".
genome(seed)genome{ id, gen, genes, from, parents }. from says which parent each trait came from.
share(trait, value)numberHow common a trait value is: share("species", "fox") is 0.16.

Options

OptionDefaultNotes
sizenoneSets width and height. Leave it out to size with CSS.
backgroundfalse"circle", "squircle" or "square", in a pale tint of the pipkin's colour.
mood"neutral"happy, sleepy, grumpy, worried, excited, determined, smug.
animatefalsetrue, or "hover" to play only while hovered. Load pipkins/motion.css once.
embedMotionfalsePuts the motion CSS inside the SVG, so it animates on its own, even as an <img>.
titlenoneAccessible name. Without it the SVG is aria-hidden.

Guarantees

  • Deterministic. The same input gives the same SVG, byte for byte. 41 pinned renders are checked on every test run.
  • Normalised names. Case, spacing and Unicode form don't change the pipkin, so "Theo " is "theo".
  • Stable traits. Each trait is hashed on its own key, so a new trait never moves the old ones. Changing how pipkins look is a major version.
  • Legible. Eyes clear 6.8:1 contrast against every body colour, and pipkins are checked down to 16 px.
  • Safe to repeat. No ids, <defs>, gradients or filters, so hundreds of pipkins can share a page.
  • Private. Nothing is stored or sent anywhere. Every pipkin on this page was drawn in your browser.
