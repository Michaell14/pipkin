Deterministic animal avatars

Every name gets a pipkin.

pipkin turns any string into a small animal avatar. The same name always gives the same pipkin, and nothing is stored. Two pipkins can have children, a team can fuse into one pipkin, and every pipkin has room to move.

      Breed
      
Two pipkins, one litter

      
Each child takes its species, body and eyes from one parent or the other, blends their colour and proportions, and has a 6% chance per trait of something new. A child's name is its lineage, so maya×theo#2 draws the same child anywhere.

    

    

      

        

        

        

        
Swapping parents gives the same litter.

      

      

        

        

      

    

  


  

    

      Fuse
      
A team becomes one pipkin

      
Members melt into one body. Each keeps their colour, their ears where they reach the top, and one eye. Order never matters, and up to nine members fit.

      Motion
      
Room to move

      
With animate: true, every moving part sits in its own group, pivoting where it should: ears at their base, eyes at their centre, the body at its feet. pipkin ships a quiet idle loop (breathing, a small bob, blinks and ear twitches), timed per pipkin so a crowd never moves in step. You can add your own animations on top.

    

    

      

        
Moods as status

        

          

      

      

        
Your own animation

        

          
Hover the pipkin: its ears wave, from four lines of CSS.


.wave:hover .pipkin-ear-l { animation: wave-l .5s 2; }
.wave:hover .pipkin-ear-r { animation: wave-r .5s 2; }
@keyframes wave-l { 50% { transform: rotate(-24deg) } }
@keyframes wave-r { 50% { transform: rotate(24deg) } }

Load pipkin/motion.css once per page, or pass embedMotion: true to put the styles inside the SVG so it also animates as an <img>. Motion stops under prefers-reduced-motion.

Guarantees

        
    
          
  • Deterministic. 41 pinned renders are checked byte for byte on every test run.
    • 
          
  • Normalised names. Case, spacing and Unicode form don't change the pipkin.
    • 
          
  • Stable traits. Each trait is hashed by its own key, so adding a trait never moves existing ones. Changing how pipkins look is reserved for a major version.
    • 
          
  • Legible. Eyes clear 6.8:1 against every body colour; pipkins are checked down to 16 px.
    • 
          
  • Safe to repeat. No ids, defs or filters, so hundreds of pipkins can share a page.
    • 
        

      

      

        
Not done yet

        
    
          
  • Publishing. The package is marked private until it has a final name.
    • 
          
  • Cross-engine bytes. Output is verified in Node and Chromium; other engines may round a coordinate differently.
    • 
          
  • Wrappers. No React, Vue or Svelte components yet. The SVG string works in all of them today.
    • 
          
  • More motion. Gaze tracking and transitions between moods are the next steps.
